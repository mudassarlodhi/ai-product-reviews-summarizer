# Fun Land Chatgpt

Monorepo with React (client) and Node.js (server), run together using concurrently.

## Setup

In root folder, packages/client and packages/server all three places run

```bash
npm install
```

## Environment

Create `server/.env`:

```env
OPENAI_API_KEY=your_api_key_here
```

## Run

From root:

```bash
npm run dev
```
